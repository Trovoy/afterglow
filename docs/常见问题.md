## 手环不亮

**先按顺序试这几步：**

1. **换新电池。** 演唱会手环里的纽扣电池大多已经没电或电量不足，这是最常见的原因；
2. **点「唤醒」，等 30 秒再点颜色。** 手环长时间没收到信号会进入休眠，需要先连续收 30 秒信号才会醒；
3. **离近一点**，先在 30 厘米内试；
4. **做一次「频率适配」**（手机页面 →「手环频率适配」），按提示观察手环有没有跟着闪；
5. **检查接线**，特别是射频模块的 1～5 号线和 3V3、GND。

**只有某些颜色不亮或会闪？** 白色、满亮度的颜色耗电最大，旧电池带不动时手环会闪烁或不亮。可以先用手机页面里的「电池检测」看看电池状态，或换个颜色试试。

**一部分手环亮、一部分不亮？** 不同批次的手环可能用了不同的电路，也可能是电池电量不同。先给不亮的换新电池。

## 距离为什么只有 1 米左右

我们用无线电测量设备实测过：控制器的发射功率已经开到国内 433 MHz 微功率设备允许的上限（10 mW），信号本身没问题。**距离受限于手环自己的接收电路**，它本来就是为演唱会现场设计的，场馆里用的是大功率发射机。

实测结果（同一个手环，不同摆法）：

| 情况 | 影响 |
| --- | --- |
| 天线没拧上 | 基本收不到，**天线必须拧上** |
| 手环平放在桌上 | 明显变差；**立起来或戴在手上**更好 |
| 控制器放进包里 | 距离缩短一半以上 |
| 天线竖着、横着 | 差别不大，竖着略好 |
| 拿在手里 | 基本没影响 |

室内墙面和桌面的反射会让个别位置变成"死点"：明明离得更近反而不亮。挪几十厘米通常就好了。

调频率、调信号参数我们也都试过，对距离没有可测到的改善，所以软件里不需要改这些设置。

## 电脑和刷机

**打开安装程序时提示「Windows 已保护你的电脑」**
点「更多信息」→「仍要运行」。软件没有购买代码签名证书，所以 Windows 会提示，这是正常的。

**打开时报错 "Failed to resolve Python.Runtime.Loader.Initialize"**
这是 0.4.1 的问题：从网上下载的文件被 Windows 锁定，软件界面加载不了。请下载 0.4.2 或更新版本的安装程序重新安装。

**Studio 找不到控制器 / 没有 COM 口**
1. 换一根数据线，很多 Type-C 线只能充电，不能传数据；
2. 拔掉重插，换一个 USB 口（尽量直接插电脑，不要插扩展坞）；
3. Windows 一般会自动装 CH340 驱动。如果设备管理器里显示未知设备，在网上搜「CH340 驱动」安装一下。

**提示端口被占用**
关掉其他可能占用串口的软件（串口助手、Arduino IDE 等），以及多开的 Studio。

**刷机失败**
1. 换数据线、换 USB 口再试；
2. 刷机时按住 ESP32 板上的 **BOOT** 键，看到开始写入后松开；
3. 选「完整安装」重新刷一次。

**以后怎么更新？**
新版 Studio 自带最新固件。连上控制器后到「烧录 / 更新」页面点更新即可，你的设置会保留。也可以用 Wi-Fi 更新，不用插线。

## 手机连接

**搜不到 Afterglow-XXXX 热点**
1. 确认控制器通电了（板子上的灯亮着）；
2. 手机靠近一点，关掉再打开 Wi-Fi 列表刷新；
3. 拔掉电源重新插上，等 10 秒再找。

**连上了但控制页面没弹出来**
打开手机浏览器，输入 `192.168.4.1`。

**手机自动断开、跳回别的 Wi-Fi**
因为这个热点不能上网，有些手机会自动切走。在 Wi-Fi 设置里关掉「自动切换到更好的网络」之类的选项；连上时如果手机问「此网络无法上网，是否保持连接」，选**保持连接**。

**热点密码忘了**
默认密码是 `afterglow88`。改过密码又忘了的话，用数据线连电脑，在 Studio 的「高级设置」里重新设一个热点密码。

## 供电

- 刷机和用 Studio 时，用数据线连电脑；
- 平时只用手机控制的话，插 USB 充电头或充电宝就行；
- 有的充电宝电流太小会自动断电，可以换一个，或者打开充电宝的「小电流模式」；
- 少数 C 口对 C 口的充电头可能不给板子供电，换一根 A 口转 C 口的线试试。

## 其他

**可以带去演唱会用吗？**
**不可以。** 本项目只用于演出结束后、在私人场合控制自己的手环。在现场使用会干扰主办方的灯光控制和其他观众。

**「演唱会复刻」是什么？**
用**你自己拍的**演唱会视频，Studio 会分析画面颜色和现场节拍，生成一段灯光时间线。回放视频时，手环会跟着变色、闪烁。软件不提供任何演唱会内容。

**一次能控制几个手环？**
范围内的手环都会同时响应，数量没有限制。

**会收集我的数据吗？**
不会。控制器只开自己的热点，不连互联网；Studio 也不联网上传任何东西。

**还有问题？**
到 [Issues](https://github.com/Trovoy/afterglow/issues/new/choose) 提交，写清楚软件版本、固件版本和操作步骤，有截图更好。
