## 目录结构

```
firmware/                 控制器固件（PlatformIO 项目）
  include/  src/          C++ 源码
  web/index.html          手机控制页面（编译前用 web/embed.py 嵌进 src/webpage.h）
  make_package.py         生成固件包 afterglow-fw-x.y.z.zip（Studio 和手机都用它更新）
studio/                   电脑端 Afterglow Studio（Windows）
  app.py                  程序入口（pywebview 窗口 + Python 后端）
  ui/                     界面（HTML / CSS / JavaScript）
  setup/                  自己设计界面的安装程序
  tests/                  离线单元测试
  build_release.ps1       一键打包：测试 → PyInstaller → 安装程序 → 压缩包
```

## 固件

**需要：** [PlatformIO](https://platformio.org/install)。装 VS Code 插件，或者 `pip install platformio`。

```bash
cd firmware
pio run                                    # 编译
pio run -t upload --upload-port COM5       # 编译并刷进控制器（COM 口换成你自己的）
python make_package.py                     # 生成 dist/afterglow-fw-x.y.z.zip
```

- 工具链版本固定为 `espressif32@6.9.0`（Arduino-ESP32 2.0.17）。**不要升级到 Arduino 3**，射频发射用到的 RMT 接口在 3.x 里改了；
- CC1101 驱动库固定在某个提交（见 `platformio.ini`），保证每次编译结果一样；
- 生成固件包前，先把 `include/version.h` 里的 `FW_VERSION` 改成新版本号。版本号已存在时 `make_package.py` 会拒绝覆盖；
- **Windows 上报 `CreateProcess: No such file or directory`**：通常是 PlatformIO 安装路径太长，超过了 Windows 的路径长度限制。把环境变量 `PLATFORMIO_CORE_DIR` 设成一个短路径，比如 `C:\pio`，再编译一次。

### 接线（引脚）

| ESP32 | CC1101（E07-M1101D） | INMP441 麦克风 |
| --- | --- | --- |
| GPIO 5 | CSN | |
| GPIO 18 | SCK | |
| GPIO 19 | MISO | |
| GPIO 23 | MOSI | |
| GPIO 27 | GDO0（发射数据） | |
| GPIO 33 / 25 / 26 | | SD / WS / SCK |
| 3V3 / GND | VCC / GND | VDD / GND，L/R 接 GND |

以 [`src/radio.cpp`](../firmware/src/radio.cpp) 和 [`src/audio.cpp`](../firmware/src/audio.cpp) 里的定义为准；面包板接法见 [DIY 指南](DIY指南.md)。

### 发射参数

默认 433.92 MHz、OOK、10 dBm，已经是国内 433 MHz 微功率设备允许的上限。请不要为了距离改大功率，距离主要受手环接收电路限制，改大功率也没有明显效果（见 [常见问题](常见问题.md#距离为什么只有-1-米左右)）。

## 手机控制页面

页面源码是 [`firmware/web/index.html`](../firmware/web/index.html)，单文件，不依赖任何外部库。

```bash
cd firmware
python web/mock_server.py        # 不接控制器预览：打开 http://127.0.0.1:8766/
python web/embed.py              # 改完后重新生成 src/webpage.h，再编译固件
```

`mock_server.py` 会模拟控制器的 `/api` 接口，可以直接在电脑浏览器里调界面。

## 电脑端 Afterglow Studio

**需要：** Windows 10 / 11，[Python 3.12](https://www.python.org/downloads/)（64 位）。

```powershell
cd studio
py -3.12 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python app.py                              # 运行
.venv\Scripts\python -m unittest discover -s tests       # 跑测试（不需要控制器）
```

- 从源码运行时，Studio 会到 `firmware/dist/` 里找固件包，先按上一节生成一个；
- 只调界面的话，可以直接用浏览器打开 `studio/ui/index.html?mock`，用的是 `ui/mock.js` 里的假数据；
- 「演唱会复刻」需要 ffmpeg：放在 PATH 里，或者设置环境变量 `AFTERGLOW_DEV_FFMPEG` 指向 `ffmpeg.exe` 所在的文件夹。

## 打包安装程序

```powershell
cd studio
.venv\Scripts\pip install -r requirements-build.txt
$env:AFTERGLOW_FFMPEG_DIR = 'D:\tools\ffmpeg-essentials'   # 解压后的 ffmpeg，里面要有 bin\ffmpeg.exe、LICENSE、README.txt
powershell -ExecutionPolicy Bypass -File build_release.ps1
```

脚本依次执行：
1. 单元测试；
2. PyInstaller 打包；
3. 打包后自检；
4. 生成安装程序（把程序附加在安装程序后面）；
5. 静默安装、卸载自检；
6. 发布检查：不允许带任何演唱会视频、音频、复刻节目；
7. 计算 SHA-256。

结果在 `studio/release/` 里。版本号取自 `app.py` 里的 `APP_VERSION`。

ffmpeg 可以到 [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 下载 essentials 版本。
